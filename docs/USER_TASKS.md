דברים שאין לי גישה אליהם: מפתחות שאני לא יכול לקרוא, מחיקת שירותים, בדיקות ידניות.
הכל אפשרי מהטלפון, בדפדפן. כשמשהו בוצע, תגיד לי ואסמן אותו כאן.

## 1. להוסיף את מפתח מזג האוויר ל־Vercel ⬅ הכי חשוב
**למה:** ה־API עבר ל־Vercel. מזג האוויר (במצב ריאליסטי) צריך את המפתח של OpenWeatherMap, ואין לי אפשרות לקרוא אותו מ־Render. בלעדיו מזג האוויר לא נטען, וכל השאר עובד.

**איך להשיג את המפתח** (אחת משתי הדרכים):
- **מ־Render:** https://dashboard.render.com → השירות `ido-communications-api` → **Environment** → ליד `OPENWEATHERMAP_API_KEY` ללחוץ על סמל העין ולהעתיק.
- **מ־OpenWeatherMap:** https://home.openweathermap.org/api_keys → להעתיק את המפתח הקיים.

**איפה להדביק:**
1. https://vercel.com → הפרויקט **`ido-communications-api`** (לא `ido-communications`)
2. **Settings** → **Environment Variables** → **Add**
3. Key: `OPENWEATHERMAP_API_KEY`, Value: המפתח, Environments: לסמן **Production** ו־**Preview**, ולסמן **Sensitive**
4. **Save**
5. **Deployments** → בפריסה העליונה (Production) ⋯ → **Redeploy**. בלי זה המפתח לא נכנס לתוקף.

**בדיקה:** לפתוח https://ido-communications-api.vercel.app/api/weather?lat=31.77&lon=35.21. צריך לראות טמפרטורה, ולא `Weather service not configured`.

## 2. לכבות את השרת הישן ב־Render (אחרי שסעיף 1 עובד)
**למה:** האתר כבר לא משתמש בו. כל עוד הוא קיים, הוא נבנה מחדש בכל push וצורך שעות מהמכסה החינמית.

1. https://dashboard.render.com → השירות `ido-communications-api`
2. **Settings** → למטה **Suspend Web Service** (אפשר להחזיר) או **Delete Web Service** (סופי)
3. מומלץ להתחיל ב־Suspend, ולמחוק אחרי שבוע בלי בעיות.

> המשימה הקודמת "לשנות את ה־Build Command ב־Render" **כבר לא רלוונטית** אם השירות נכבה.

## 3. להתחבר מחדש לאתר (פעם אחת)
**למה:** לשרת החדש יש מפתח חתימה חדש, אז החיבור הקודם שלך כבר לא תקף. האנטנות וההיסטוריה שמורים במסד הנתונים ולא נמחקו.

1. https://ido-communications.vercel.app → התחברות עם אותו שם משתמש וסיסמה.
2. לבדוק שהאנטנות וההיסטוריה מופיעים.

## 4. בדיקות ידניות קצרות (כשיש לך דקה)
- [ ] **חיפוש מקום במפה** (למשל "חיפה") בעמוד LOS: מופיעות תוצאות, ובלחיצה עליהן נפתח פופאפ. אני לא יכול לבדוק את זה, כי Nominatim חוסם שרתי ענן.
- [ ] **חישוב שטח מול חישוב קו** באותה נקודה: לבחור נקודה ירוקה במפת השטח ולחשב אליה קו מאותו מוצא, עם אותם גבהים (ברירת המחדל עכשיו זהה: 10 מ׳ / 2 מ׳). התוצאה צריכה להיות זהה. אם לא, לשלוח לי את הקואורדינטות.
- [ ] **צבעים חדשים במפת השטח:** כתום = חסום בפחות מ־3 מ׳ (גבולי, בתוך טווח הדיוק של נתוני הגובה); צהוב = במצב RF יש קו ראייה אבל אזור פרנל חסום.
